DOCUMENTACIÓN DEL LENGUAJE

Reglas de Algora.

Una sintaxis pequeña, consistente y pensada para quienes comienzan a programar.

01 / ESTRUCTURA

Inicio y fin

Algoritmo MiPrograma
    Escribir("Hola mundo");
FinAlgoritmo

Todo programa comienza con Algoritmo nombre y termina con FinAlgoritmo.

02 / VARIABLES

Declarar y asignar

Definir edad Como Entero;
Definir precio Como Decimal;
Definir nombre Como Texto;
edad = 18;

Los tipos son Entero, Decimal y Texto. Toda variable debe declararse antes de usarse.

03 / ENTRADA Y SALIDA

Leer y escribir

Leer(edad);
Escribir("Edad: ", edad);

Leer solicita datos desde la consola; Escribir admite una o varias expresiones.

04 / CONDICIONALES

Si / SiNo

Si edad >= 18 Entonces
    Escribir("Mayor");
SiNo
    Escribir("Menor");
FinSi

Comparadores: ==, !=, >, <, >= y <=. SiNo es opcional. Admite anidamiento.

05 / EXPRESIONES

Aritmética

total = (12 + 8) * 2 / 5;
negativo = -3;

Multiplicación y división tienen prioridad sobre suma y resta. Se respetan los paréntesis.

06 / CONVENCIONES

Reglas generales

// Comentarios de una línea
Escribir("Texto entre comillas");

Usa punto y coma al final de instrucciones simples. Los identificadores distinguen mayúsculas; las palabras reservadas no.
